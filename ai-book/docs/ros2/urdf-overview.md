# URDF Overview - Unified Robot Description Format

The **Unified Robot Description Format (URDF)** is an XML format used in ROS to describe all aspects of a robot. It's a foundational tool for representing a robot's physical structure, visual properties, and inertial characteristics. Understanding URDF is crucial for simulating robots, performing motion planning, and visualizing robot models in tools like Rviz.\n\n## 1. Why URDF?\n\nURDF provides a standardized, human-readable way to describe a robot. Its key benefits include:\n\n*   **Standardization**: A common format for robot descriptions across the ROS ecosystem.\n*   **Visualization**: Allows tools like Rviz to accurately display the robot's kinematics and sensor data.\n*   **Simulation**: Enables simulation environments (e.g., Gazebo) to load robot models and simulate their physics.\n*   **Motion Planning**: Provides kinematic and dynamic information necessary for motion planning algorithms.\n*   **Modularity**: Robot descriptions can be built from smaller, reusable components.\n\n## 2. Core Concepts: Links and Joints\n\nA URDF model is essentially a tree structure composed of **links** and **joints**.\n\n### Links\n\n*   **Definition**: A **link** represents a rigid body of the robot. This could be a robot arm segment, a wheel, the base, or any other physical part that moves as a single unit.\n*   **Properties**: Links have various properties that describe their physical characteristics:\n    *   **Visual**: Defines the geometry (e.g., box, cylinder, mesh), color, and texture of the link for visualization.\n    *   **Inertial**: Describes the link's mass, center of mass, and inertia tensor, crucial for physics simulation.\n    *   **Collision**: Defines the collision geometry of the link, used for collision detection in simulations and motion planning.\n\n**Example of a Link in URDF**:\n\n```xml\n<link name=\"base_link\">\n  <visual>\n    <geometry>\n      <box size=\"0.6 0.4 0.2\"/>\n    </geometry>\n    <material name=\"blue\">\n      <color rgba=\"0 0 0.8 1\"/>\n    </material>\n  </visual>\n  <collision>\n    <geometry>\n      <box size=\"0.6 0.4 0.2\"/>\n    </geometry>\n  </collision>\n  <inertial>\n    <mass value=\"10\"/>\n    <inertia ixx=\"1.0\" ixy=\"0.0\" ixz=\"0.0\" iyy=\"1.0\" iyz=\"0.0\" izz=\"1.0\"/>\n  </inertial>\n</link>\n```\n\n### Joints\n\n*   **Definition**: A **joint** connects two links, defining their kinematic relationship and the type of motion allowed between them. Joints form the hierarchical structure of the robot.\n*   **Types**: URDF supports several joint types, each allowing different degrees of freedom:\n    *   **`revolute`**: A rotational joint around a single axis (e.g., a hinge, a robot arm joint).\n    *   **`continuous`**: Similar to revolute, but without joint limits (e.g., a wheel that can spin infinitely).\n    *   **`prismatic`**: A translational joint along a single axis (e.g., a linear slide).\n    *   **`fixed`**: A rigid connection between two links, removing all degrees of freedom. Useful for grouping parts of a robot that don\'t move relative to each other.\n    *   **`floating`**: A 6-DOF joint, typically used for the base link of a robot to represent its movement in 3D space.\n    *   **`planar`**: A 3-DOF joint that allows movement in a plane.\n*   **Parent and Child Links**: Each non-root joint connects a `parent` link to a `child` link. The motion of the child link is defined relative to its parent.\n\n**Example of a Joint in URDF**:\n\n```xml\n<joint name=\"base_to_wheel_left\" type=\"continuous\">\n  <parent link=\"base_link\"/>\n  <child link=\"left_wheel_link\"/>\n  <origin xyz=\"0.2 0.2 0\" rpy=\"0 0 0\"/>\n  <axis xyz=\"0 1 0\"/>\n</joint>\n```\n\n## 3. URDF Structure and Hierarchy\n\nA complete URDF file typically starts with a `<robot>` tag, containing all `<link>` and `<joint>` definitions. The joints define the tree-like kinematic chain, starting from a root link (often `base_link` or `odom`).\n\n```xml\n<?xml version=\"1.0\"?>\n<robot name=\"my_simple_robot\">\n\n  <!-- Base Link Definition -->\n  <link name=\"base_link\">\n    <!-- Visual, Collision, Inertial properties -->\n  </link>\n\n  <!-- Left Wheel Link Definition -->\n  <link name=\"left_wheel_link\">\n    <!-- Visual, Collision, Inertial properties -->\n  </link>\n\n  <!-- Joint connecting base_link to left_wheel_link -->\n  <joint name=\"base_to_wheel_left\" type=\"continuous\">\n    <parent link=\"base_link\"/>\n    <child link=\"left_wheel_link\"/>\n    <origin xyz=\"0.2 0.2 0\" rpy=\"0 0 0\"/>\n    <axis xyz=\"0 1 0\"/>\n  </joint>\n\n  <!-- Repeat for other links and joints -->\n\n</robot>\n```\n\n## 4. Xacro: Simplifying URDF\n\nWriting complex robot descriptions purely in URDF can be verbose and repetitive. **Xacro (XML Macros)** is a preprocessor for URDF that allows for:\n\n*   **Macros**: Define reusable blocks of XML that can be instantiated multiple times.\n*   **Variables**: Use variables to avoid hardcoding values (e.g., dimensions, masses).\n*   **Arithmetic Operations**: Perform calculations within the XML.\n\nXacro greatly simplifies the creation and maintenance of complex URDF files. A typical workflow involves writing robot descriptions in Xacro (`.urdf.xacro` files) and then converting them to standard URDF (`.urdf` files) for consumption by ROS 2 tools.\n\n## Conclusion\n\nURDF is the standard language for describing robots in ROS 2, providing a rich framework for defining a robot\'s physical structure, visuals, and dynamics through links and joints. Coupled with Xacro for enhanced readability and reusability, URDF forms the foundation for robot simulation, visualization, and advanced motion planning in robotics applications.
